🏠 NestKeep — Hostel & PG Management System

NestKeep is a web-based Hostel and Paying Guest (PG) Management System designed to simplify hostel administration.

Features

- Dashboard displaying hostel statistics
- Room management and bed capacity tracking
- Add and delete rooms
- Duplicate room number validation
- Responsive user interface
- Browser-based data persistence using Local Storage

Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

How to Run

1. Download or clone this repository.
2. Open "index.html" in a web browser.
3. Add rooms and explore the room management functionality.

Future Improvements

- Resident registration and room allocation
- Rent payment tracking
- Complaint management
- Light and dark themes
- Backend database integration
